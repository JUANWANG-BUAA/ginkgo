# Typeface assets

Open source approximations for cross-platform visual alignment:

- `Inter.ttf`: Inter variable font (opsz/wght), Latin UI, from https://github.com/google/fonts/tree/main/ofl/inter. License: `Inter-OFL.txt`.
- `NotoSansSC.ttf`: Noto Sans SC variable font (wght), Simplified Chinese, from https://github.com/google/fonts/tree/main/ofl/notosanssc. License: `NotoSansSC-OFL.txt`.

Retrieved 2026-10-20 after checking local font assets. Both use SIL Open Font License 1.1. No Apple system font is bundled. Flutter family aliases are `Ginkgo Sans` and `Ginkgo Han`; binaries are unmodified upstream files.
