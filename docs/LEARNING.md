# 开发随记

## 网格与预约

- 将复杂 SwiftUI 表达式拆成独立单元格组件，可降低编译器类型推导负担。
- 重叠课程按连通的时间区间统一分栏，避免每张卡片各自计算宽度导致覆盖。
- 预约请求失败可能发生在服务器已受理之后，因此界面提示核实预约记录，不能自动重发。
- CommonCrypto AES-CBC 开启 PKCS7，与独立 OpenSSL 密文向量交叉校验。

## 课表与成绩

- `Codable` 把课程快照编码为本地缓存；读取失败时重新请求学校服务。
- 请求代次用于阻止较早请求覆盖较新的学期/周次选择。
- 日期必须绑定学校时区；设备时区不同可能导致周日/周一边界判断错误。
- 空数据只在成功解析上游响应后成立；网络失败和解析失败应显示未知状态。
- 成绩查询只依赖学期列表，避免空课表或课表格式变化阻断成绩服务。

## CAS 登录模块（2026-10-15）

| 概念 | 一句话解释 | 本项目中的例子 |
|------|------------|----------------|
| `actor` | 由 Swift 串行管理内部可变状态的类型。 | `CasClient` 持有认证会话并执行请求。 |
| `async/await` | 等网络完成时挂起当前任务，避免卡住界面。 | `AuthViewModel` 等待 `fetchLoginPage()` 和 `login()`。 |
| `enum` 关联值 | 一个结果可以是几种明确情况，每种携带自己的数据。 | `LoginPageResult` 区分登录页与已有会话跳转。 |
| `URLProtocol` | 在测试中拦截 `URLSession` 请求并返回合成响应。 | `CasClientTests` 模拟 302、错误页和 UC 状态。 |
| percent 编码 | 把表单值中的特殊字符编码后再发送，避免被服务器错读。 | `CasFormParser` 将 `execution` 中的 `+` 编为 `%2B`。 |

## 会话管理模块（2026-10-15）

| 概念 | 一句话解释 | 本项目中的例子 |
|------|------------|----------------|
| Keychain | 系统提供的受保护凭据存储。 | 用户勾选记住密码后，`KeychainManager` 才保存账号密码。 |
| 依赖注入 | 把外部服务从外面传给对象，便于替换和测试。 | `AppState` 在测试中接收模拟认证服务与模拟凭据库。 |
| 状态驱动界面 | 界面跟随状态值变化，不直接手动切换页面。 | `isRestoring` 显示检查进度，`isLoggedIn` 决定显示登录页或主界面。 |
