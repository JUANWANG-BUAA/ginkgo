## Swift 设计原则的体现

| 原则 | 体现 | 代码 |
|-----|------|------|
| **Clarity** | 清晰的信息层级：徽章 > 标题 > 副标题 | Container with background |
| **Depth** | 渐变 + 精细阴影 | LinearGradient + BoxShadow |
| **Responsiveness** | 即时的 120ms 按下反馈 | AnimationController + ScaleTransition |
| **Consistency** | 所有间距/色彩用设计系统 | GinkgoColors / GinkgoSpacing |
| **Beauty** | letter-spacing (-0.2, -0.1) 的精妙 | TextStyle.letterSpacing |
| **Deference** | 装饰最小化，内容优先 | 去掉了不必要的视觉元素 |
