# Swift 设计质感优化 - 改进清单

## ✅ 已实施的核心改进

### 1. TodayActionRow 组件（已完全重写）✨

这是"今天"页面中所有卡片的基础组件。

#### A. 排版层级优化

**改进前：**
- 字号混乱 (13/15/17/20px)
- fontWeight 不一致 (w400/w500/w600)
- letter-spacing 硬编码或无

**改进后：**
```
标题字号       18px (emphasized) / 16px (normal)
标题粗度       w700 (emphasized) / w600 (normal)
标题间距       -0.3 (emphasized) / -0.2 (normal)
副标题字号     13px
副标题粗度     w400
副标题间距     -0.1
状态标签       11px w600 uppercase (0.2 letter-spacing)
```

**在模拟器看到的变化：** 主标题看起来更有力量感，副标题更柔和，整体更有呼吸感

---

#### B. 状态标签设计 - 从纯文本到徽章 🏷️

**改进前：**
```
"下一节课" (纯文本)
```

**改进后：**
```
┌─────────────────┐
│ 下一节课        │  ← 有背景、有圆角、有 padding
└─────────────────┘
```

代码实现：
- 半透明彩色背景 (opacity: 8% light / 12% dark)
- 圆角 6pt
- 水平 padding: 8pt，垂直 3pt
- 大写字母间距 (letter-spacing: 0.2)

**在模拟器看到的变化：** 状态信息从纯文本变成清晰的徽章，一眼就知道这是"状态"而不是标题

---

#### C. 卡片深度感 - 阴影和渐变

**改进前：**
```
背景: 纯色 (8-14% opacity)
边框: 1px，颜色 18-26% opacity
效果: 完全扁平，没有深度感
```

**改进后：**
```
背景: 渐变 (5% → 1% opacity，从左上到右下)
边框: 0.8px，颜色 12-15% opacity（更细致）
阴影: blur 6pt, offset (0, 1), color opacity 8-12%
效果: 有明显的立体感和光学效果
```

**在模拟器看到的变化：** emphasized 卡片从平面变成有明显深度感的"浮起来"的卡片

---

#### D. 交互反馈 - 按下动画 🎬

**改进前：**
```
按下：无动画
松开：无动画
体感：呆滞
```

**改进后：**
```
按下时:
  - 卡片缩小到 97% (scale animation)
  - 透明度变为 70% (opacity animation)
  - 时长 120ms (snappy)
  - 曲线 easeInOut

松开时:
  - 流畅恢复到原大小和透明度
  - 时长 120ms (snappy)

体感：流畅、有反馈、有趣
```

**在模拟器看到的变化：** 按下卡片时能明显感受到它在"被按下"，有明显的物理反馈

---

#### E. 间距系统 - 严格栅栏化

**改进前：**
```
随意的 margin 和 padding 值
emphasized: (16, 14) padding
normal: (16, 10) padding
```

**改进后：**
```
所有间距都遵循 GinkgoSpacing 常量:
- Emphasized margin: (12, 8)
- Normal margin: (4, 6)
- Content padding: (16, 14) 或 (16, 12)

所有值都是 4pt 的倍数（8pt 栅栏）
```

**在模拟器看到的变化：** 页面看起来更整齐，元素对齐更精确

---

#### F. 色彩系统 - 语义化

**改进前：**
```
statusColor 参数随意应用
alpha 值硬编码
深浅色模式处理不一致
```

**改进后：**
```
使用 GinkgoColors 语义化色彩:
- GinkgoColors.accent (强调)
- GinkgoColors.label (主文本)
- GinkgoColors.secondaryLabel (次文本)
- GinkgoColors.tertiaryLabel (弱文本)

色彩在深浅色模式下自动调整
Alpha 值根据模式变化 (isDark ? ... : ...)
```

**在模拟器看到的变化：** 从浅色切到深色模式，卡片的配色、边框、阴影自动适应，没有任何破损

## 🎯 Swift 设计特征体现

| 设计原则 | 实现方式 | 模拟器可观察 |
|--------|--------|-----------|

| **Beauty** | letter-spacing、gradient、shadow 微妙配合 | 整个页面看起来更精致 |

## 💡 为什么这是真正的 Swift 质感

1. **不只是样式** - 是排版、色彩、动画、间距的完整系统
2. **即时可感受** - 打开页面就能看到卡片有阴影和渐变

4. **响应式交互** - 按下时有明显反馈，不是虚设
5. **自适应深浅** - 不是固定样式，根据环境智能调整
