## 发现与修复

定位：[resolve_symlinks.ps1](../../../flutter/rust_builder/cargokit/cmake/resolve_symlinks.ps1)、[cargokit.cmake](../../../flutter/rust_builder/cargokit/cmake/cargokit.cmake)。

Windows CMake 调用 powershell.exe（5.1），原脚本读取 PowerShell 7 的 LinkTarget，实际未解析 Flutter 插件别名，最终从 ephemeral 目录寻找错误的 Rust manifest。改用 5.1 支持的 Target，接受斜杠 / 反斜杠、带空格的 junction，使用 LiteralPath；缺路径立即失败。CMake 检查解析进程退出码，不再继续使用貌似有效的错误路径。

首次失败配置留下 Program Files 安装前缀缓存；清除生成的 CMakeCache.txt 后普通用户构建恢复，未修改项目安装权限或提升进程。新增 [Windows 路径回归](../../../scripts/check-mirror-windows-paths.ps1)，在 Windows PowerShell 5.1 实测直接路径、空格 junction、缺路径失败；CI Windows job 加入同一入口。
