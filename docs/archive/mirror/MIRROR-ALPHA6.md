# Alpha.6：提醒、诊断与教学楼研讨室预约

更新：2026-10-22；源码版本 `0.1.0-alpha.6+7`。Android / Windows 镜像的本轮实现，不代表已修改或发布 SwiftUI Apple 应用。

## 功能与边界

- **签到门禁**：北京时间课前 10 分钟开放，课程结束关闭；页面与 Rust 提交前都检查。仅当日、未签到、无冲突且唯一上游签到 ID 的课程可提交。每节课一个提醒键；不自动签到。
- **作业提醒**：仅个人课程中确认未完成、截止时刻可解析且未过期的作业，在截止前 48 / 24 小时安排。首次发现已不足一天时只补当前阶段，不同时弹两条旧提醒；提交状态变更后撤销相应计划。
- **未读 tips**：手机标签与桌面侧栏共用红色数字角标。进入对应页面清除当前阶段未读，不会把作业标为已完成；下一提醒阶段可再次未读。阅读摘要按账号 SHA-256 隔离，摘要不是加密。
- **Android 系统通知**：使用系统非精确 AlarmManager，无精确闹钟权限、后台服务或后台学校请求。正文不含账号、课程、作业名称或地点；拒绝权限时仍保留应用内角标。系统投递记录按稳定摘要去重，数据更新 / 关闭开关 / 登出取消排程。重启设备、强行停止、厂商省电可能丢失或延迟提醒，重新打开应用重排。Windows 当前只有应用内提醒，不能称为后台系统通知。
- **刷新覆盖**：登录工作区前台每两分钟只读刷新，失活停止轮询；课程只覆盖已读到的当天 iclass 记录，不推算未读取课程。工作台既有作业读取同时更新提醒，避免启动时再发一份 SPOC 请求；失败保留旧计划，提醒用户进入页面核对实际状态。
- **错误 hint**：统一错误码映射触发轻量提示，查看时显示行动建议并可复制最近 50 条脱敏诊断。仅保留本次进程的错误码和 UTC 时间，不记录原始异常、URL、响应正文、表单或个人信息。普通成功加载不创建错误记录。
- **CGYY**：沿用 API §6B 与现有 Swift / UBAA 对照协议，固定直连。读取用途与空档 → 填表 → 二次确认 → 创建草稿 → 用户手动拼图 → 再核对空档 → 单次提交 → 查询订单。取消前检查当前订单及开始前四小时限制。POST 不重放；不确定结果暂停后续写入，只有成功只读回查且用户确认已核对才解除保护。门锁码尚未迁移。

## 新 UI 的 iOS 对照

基准为 `BUAA-Assistant-iOS/Sources/Native/IOSCgyyView.swift`，不只以“使用 Cupertino”作为完成标准：

| 项目 | 镜像落实 |
| --- | --- |
| 信息顺序 | 场地与日期 → 选择空间与时段 → 预约信息 |
| 空间选择 | 单空间、多时段网格，已选文字与颜色共同表达；不以颜色推断可写 |
| 表单 | 手机号、活动主题、活动类型、人数步进器、活动内容、参与人说明、两个原生风格开关 |
| 提交 / 取消 | Cupertino 二次确认；不确定状态只引导回查，不给自动重试 |
| 深浅色 / 大字号 | 动态系统背景与语义文字；320 / 430 / 900 逻辑宽度、1.3 倍字体合成渲染；控件触控区域至少 44 pt |
| 提醒与诊断 | 统一未读胶囊、分组设置、原生风格提示 / 确认弹窗，无 Material 表单或独立视觉体系 |

本轮已检查合成页面渲染；**没有完成 iOS / Android 实机逐像素截图对照或完整 VoiceOver / TalkBack 验收，不宣称跨渲染器像素完全相同**。Android 系统通知外观由 Android 系统绘制，无法替换成 iOS 系统通知。
