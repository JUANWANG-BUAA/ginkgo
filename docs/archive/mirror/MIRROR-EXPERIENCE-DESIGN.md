## 2. 导航方案与任务路径

手机五个一级入口：**工作台 · 签到 · 课表 · 作业 · 预约**。

- 工作台：当天课程摘要 → 四个核心任务入口 → 个人待办 / 学业 / 校园服务。账户设置在导航栏齿轮与首屏“账户与设置”行，演示模式同样可达。次级模块按任务分组，不再堆进“更多”。
- 签到：当天课程和已确认状态 → 课程详情。查询失败给出重试与连接提示；本轮不开放提交。
- 课表：学期与当前周 → 清单/周视图/学期 → 搜索与课程详情。手机与宽屏默认周网格；顶部“周课表/每日清单/学期/考试”明确切换（考试需有数据），大字号自动清单。保留每个入口的导航栈与浏览位置。
- 作业：学期 / 来源上下文 → 状态筛选和计数 → 作业列表 → 详情。截止时间与提交状态优先于技术来源描述。
- 预约：图书馆座位、研讨室与场馆两个资源入口；空教室作为查询工具。进入业务页后展示各自“我的预约/订单”，不在首页并发触发所有认证。页面明确当前可查范围，不能把只读称为预约提交完成。

桌面用分组侧栏表达同一分类：工作台（今天、签到、待办）；学业（课表、作业、成绩、博雅、研究生）；空间（图书馆、研讨室、空教室）；校园（通知）；底部固定设置。仅首次访问时构建页面。内容宽度由实际可用宽度决定，不能用含侧栏的窗口总宽误判网格可读性。

## 3. 视觉与组件层级

| 层级 | 规格与用途 |
|---|---|
| 页面 | 34pt 大标题、16pt 页边；滚动后系统紧凑标题；刷新/账户用现有 AppleGlassButton |
| 范围 | 学期为次级选择；当前周与起止日期为主锚点；周条初始定位选中周，不从第一周盲滚 |
| 视图切换 | 系统分段控件；搜索紧邻结果；不把所有范围控件塞进一张巨大卡片 |
| 内容分组 | 圆角 26pt inset grouped；组间留白；日期/状态作为组头，避免标题反复套卡 |
| 主信息 | 课名 / 作业标题 17–18pt 半粗；时间 20–22pt 数字；教师/来源 13–15pt 次级 |
| 颜色 | 中性背景和文字构成主体。功能图标用蓝/橙/靛/紫等稳定识别色；课程名稳定散列到多色调色板。绿只代表已确认成功，红/橙表达异常或期限，状态同时写文字 |
| 课表清单 | 左侧开始/结束时间与节次；色条；课名、地点、教师。没有时间就写未提供，不猜固定作息 |
| 课表网格 | 七列填满可用宽度；表头带日期、今天轻高亮；可见时间轴、课程色块、地点。冲突课程分栏，不能覆盖；窄屏显式提示左右滑动，大字号优先清单 |
| 详情 | 推入详情页，完整时间、日期、节次、地点、教师、周范围；不用 ActionSheet 承载信息 |
| 状态 | 首次加载、确认空、搜索无匹配、缓存过时、失败分别表达；刷新失败保留旧内容和实际范围 |

“原生感”由导航行为、排版、留白、系统语义色与控件状态共同构成；不再增加装饰玻璃。Flutter 近似不宣称 macOS 原生控件或像素一致。

## 5. 执行与验收顺序

1. 先修时间解析、查明图书馆/签到失败阶段；只输出阶段/错误码/条数，不记录真实数据。
2. 按本设计重组入口与工作台，随后改课表范围层级、时间轴、颜色和冲突布局；再整理作业与资源页面。
3. 仅针对改动做解析/应用关键回归与 widget；设备只跑独立 smoke，不重跑 mirror_test.dart。
4. 合成数据查看浅/深色、大字号；真实登录会话只做只读操作，分别记录成功、空结果、失败及未验证，不截取真实账号页面。
5. 验收结束退出并确认 Android 保险库为空。Windows 未实机继续保留未验收。

完成标准是导航任务可达、信息可读、真实链路有结果或明确可定位的错误；自动化全绿不能替代这三项。

## 启动与公共信息交互补充

沿用现有五入口与独立导航栈，本轮不重排业务。启动时用现有叶片图标与Ginkgo字标作一次280ms轻微缩放/淡入；会话恢复立即开始，不设最低展示时间、不等待动画结束。减少动态效果直接展示静态标识及状态，不创建自定义动画容器。加载状态与登录失败仍分开，重试沿现有会话路径。

公共统计位于图书馆首组，认证失败仍可达；人数为主、资源余量次级，缺值不当零。沿用Cupertino大标题、下拉刷新及AppleSection，不增加装饰玻璃。真实只读验收仅记录状态/条数，完成后正式登出。
