# 静态架构分析工具修正（2026-11-05）

原依赖图生成器只读单引号 package 导入，漏掉相对路径，无法支撑完整架构判断。本轮补充单双引号、相对路径、条件 import/export 候选和 part，排除常规注释/字符串伪指令，对不存在的本地目标显式失败，并输出跨目录边的文件与行号。

同一输入生成目录级和文件级强连通分量，遍历排序保证输出稳定。Rust 依赖通过 cargo metadata --no-deps --offline --locked 获取声明，不手写 crate 依赖表。手工拓扑文档删除重复目标图和过时例外，只保留职责约束、工具入口与覆盖边界。

本轮没有改应用或网络实现。词法扫描不是 Dart analyzer AST，尚未完整支持嵌套块注释、URI 转义及所有语言边角；条件导入计入全部候选可能高估实际平台边。生成绑定不作为扫描源；报告不是动态调用图、隐私审计或业务验收。Rust 不展开实际 feature/target 激活图。

find-skills 检索得到 Flutter 架构指导候选，未完成其实现质量验证，未安装或据此修改工程；本轮采用仓库自有生成器、Cargo metadata 和既有方向门禁。

当前报告未发现多文件强连通分量。平台启动更新仍含设置导航，学习快照页依赖设置中的通用外壳，以及自检依赖过宽，已登记唯一 TODO，不以修正图表代替这些实现优化。

验证：生成器四项测试、架构门禁及 27 项自测、文档链接、协议摘要和网络冻结检查通过。以父提交生成器执行相对双引号导入夹具，确认旧实现漏报；新测试覆盖该反例。两个不同 PYTHONHASHSEED 下 --check 均通过，输出稳定。git diff --check 通过。本轮仅改静态工具与文档，未重跑应用全量或设备测试。
