# Android 正常安装包实测与 UI 修正（2026-10-26）

## 环境与范围

使用 `emulator-5580`（Android 17 / API 37、ARM64），安装正常 `lib/main.dart` 入口的 Debug APK，通过 ADB 原生点击、滑动、输入与系统返回操作。不是 integration_test 测试入口。应用选择“先看看离线演示”，数据均为合成数据；未输入账号密码，未执行上传、提交、购票或预约。

默认 1080×2400、420dpi、字号 1.0、浅色；窄屏检查使用 320dp、系统字号 1.6、深色（首次 960×2100/480dpi，复验使用原物理分辨率/540dpi）。结束后恢复原分辨率、420dpi、字号 1.0、浅色。临时 UI XML 仅含合成信息，检查后删除。

## 实测发现与改动

1. 课表首屏控制区偏高。普通字号、卡片宽度至少 360dp 时，学期与周次并排，日期并入周次，返回本周放在周次条旁；窄屏和大字号继续分行，避免强行挤压。相同默认设备，搜索框顶部从 1029px 提前到约 887px，课程内容向上约 54dp。保留学期、周次选择器、周次横滑和本周定位。
2. 周次按钮触控高度不足 48dp，且 Android 大字号实测发现未选中的“第 3 周”文字换行后溢出。测量与按钮统一使用 actionTextStyle，分别测量常规/加粗字体并向上取整；文字保持单行，按钮至少 48dp。复拍已无该溢出。
3. 已提交作业仍显示橙色“已超期”倒计时，与提交状态冲突。已提交列表只保留历史截止日期、提交状态；未提交项目继续保留相对截止提示。新增回归断言。
4. “SPOC 学习、研究生学分图、本人借阅”已在功能登记表，却缺少手机工作台服务目录入口。目录新增三项，复用登记表标题、图标、页面工厂和注入账号上下文。验证入口可达、账号透传和借阅需显式读取。
5. 从目录打开 SPOC 学习，课程成功返回却弹出错误诊断。原因是 `_refresh` 为 fallbackError 提前调用有记录副作用的 `failureMessage(null)`。改为无副作用文案；异常仍由 RefreshSection 捕获记录，实际学校失败仍记录类型化诊断。新增成功首次读取/刷新均不新增诊断的测试。
6. 完整门禁暴露桥接测试不稳定：空账号学习查询先初始化真实运行时，随后并行退出测试可能进入真实注销路径。空账号现在先拒绝，再考虑初始化；增加合成测试不创建 live runtime 的断言。退出测试与生产退出逻辑保持原样。未改变有效账号的认证方式、Cookie 或网络策略。
