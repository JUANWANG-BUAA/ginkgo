## 2. 本次真实只读探查

宿主 macOS arm64，执行当前 Rust production trait 的 `learning_probe`（network feature、本机 stable Rust 1.99）。输入凭据仅在受控进程 stdin 传入，不进入源码、fixture 或此报告；不导出原始终端/学校响应。程序不打印账号、课程/栏目/文件标识、名称、token、正文或原始响应。PTY 工具的“敏感输入”标记不保证终端 echo 被屏蔽，后续运行必须先关闭 echo；本次原始进程观测不得导出或作为可共享附件，只保留本文手工脱敏计数。

默认路线与显式 `--webvpn` 各一次，顺序抽查课程列表的前两项；两次均正常退出、未触发 180 秒上限。默认路线只称“默认路线”，不将自动选择的结果推断为强制直连。随后为验证资料下载候选，增加一次显式 WebVPN 的 `--download-first-resource` 受限运行：同样仅前两课程、最多一个明确可下载文件；实际未遇符合资格的文件，没有触发下载，未扩大扫描或放宽学校下载标记。
