# SPOC 文件模块真实只读验收

时间：2026-10-26（北京时间）。用户明确要求测试真实链路；凭据仅通过测试进程 stdin 传入，不保存到代码、文档或保险库。真实文件只在内存中核对文件头和字节数，不落盘、不入库。账号、姓名、课程名、作业/文件 ID、Cookie/token 和原始响应均不记录。

## 执行路径

使用当前 `ginkgo_upstream` 的 ReqwestTransport → Session → SchoolClient 真实实现，运行 `examples/homework_live_read.rs`，不是官网浏览器 UI 代替客户端。`GINKGO_MANUAL_LIVE_NETWORK=1` 显式启用，普通 cargo test 不访问学校。分别运行默认路线及显式 `--webvpn`。

| 步骤 | 默认路线 | 显式 WebVPN |
| --- | --- | --- |
| CAS 登录及 UC 身份校验 | 通过 | 通过 |
| SPOC token / 角色 / 学期 / 列表分页 | 16 项，无陈旧回退 | 16 项，无陈旧回退 |
| 学生课程归属、两项原有详情 | 通过 | 通过 |
| 新文件 workspace（方式/次数/附件） | 两项通过 | 两项通过 |
| 教师附件鉴权下载 | 43,413 字节，PDF 文件头 | 43,413 字节，PDF 文件头 |
| 已提交附件鉴权下载 | 首轮未抽查 | 3,200,881 字节，PDF 文件头 |
| 退出会话 | 完成 | 完成 |

两项样本均为文件提交方式、次数上限 9999，已提交次数分别为 0 和 1。两项详情正文为空，但附件不为空，验证了正文空不等于没有要求。仅核对二进制文件头和大小，不宣称 PDF 全文解析或内容正确性已验证。

## 实网发现并修复

首轮登录、列表和旧详情成功，新 workspace 报 ChangedResponse：普通详情请求错误添加了提交编辑页参数 `falg=xstj`，服务器对该请求返回 `content:null`。删除普通只读查询中的此参数后，两条真实路线均恢复。新增回归 `homework_file_read_uses_detail_query_not_editor_permission_query`，断言详情 query 仅传编码后的 id。

首轮验收程序在退出后释放内部 Tokio runtime 时发生 drop panic；将 SchoolClient 放入 spawn_blocking 释放后复测 exit code 0。此修正属于可释放的示例程序生命周期，不改学校协议。

修正后 homework_file 定向 13 项通过，包含真实问题回归；其余模拟写入测试仍是合成协议证据，不升级为上游写入已验证。

## 未执行与剩余边界

未调用上传、合并、最终提交或删除接口，没有更改作业记录。真实上传/提交仍默认关闭，分片协议仍属待验收候选。需要用户明确指定目标作业和最终文件，并确认覆盖/正式提交风险后，才能继续真实写入验收。只读链路通过不表示上传/提交通过，桌面 Rust 测试也不替代 Android 真机文件选择/保存完整操作。

复现入口：`cargo run -p ginkgo_upstream --example homework_live_read --features network [-- --webvpn]`，凭据通过 stdin 输入，必须显式设置上述 live 开关。不要将密码直接放进命令行参数或提交到仓库。
