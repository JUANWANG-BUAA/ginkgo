# 发布说明

## Ginkgo 0.1.0-alpha（2026-10-16）

首个 alpha 基线，面向本人及少量熟人测试者。只读链路是验收重点；写操作仍属未验收范围。

### 包含模块

- **登录与会话**：CAS 登录、验证码分支、可选钥匙串保存、启动会话验证与静默恢复、登出。
- **今天与课表**：今日课程、本科/研究生周网格与学期总览、课程详情、本科考试安排、课程快照缓存。
- **成绩**：学期切换、成绩列表、参考绩点与加权均分。
- **图书馆**：楼馆/分区/当前时段座位查询、预约记录、确认预约/取消；官网公开在馆人数与沙河阅览室数据、本机小时趋势。
- **空教室**：校区/日期查询、楼栋概览/房间列表/节次对照、搜索与筛选排序、短时缓存。
- **学校作业**：SPOC 只读列表与详情（希冀来源暂时下线，代码与测试保留，见下方限制）。
- **内置更新**：从 GitHub Releases 检查新版本，可一键下载安装；安装只替换应用包，不清除课表、成绩缓存与本机待办。
- **课程签到**：iclass 只读状态查询、按日历史、逐课程人工确认的手动签到与提交后回查。
- **待办**：本机任务、截止时间、完成/恢复/删除，按账号摘要隔离。
- **系统集成**：菜单栏面板、全局快捷键 ⌃⌥B、登录时自动启动、课前 10 分钟提醒、签到状态通知。

### 验证证据（2026-10-16）

- `xcodebuild test`：141 项测试、0 失败（含空教室后台筛选一致性、研究生周次半开区间、希冀来源下线、版本比较与更新下载源回退）。
- **自更新端到端验证**：用 `0.1.0-alpha.1` 测试构建检查到 `v0.1.0-alpha.2`，经镜像下载、校验和比对、替换应用包并重启，版本变为 `0.1.0`；课表/成绩缓存与本机待办、登录会话均保留。
- `xcodebuild build -configuration Release`：通过。
- `git diff --check`：通过。
- 研究生账号真实观察：登录/恢复、当前学期课表（修复后刷新成功）、成绩空列表、图书馆公开人数、空教室查询、SPOC 作业列表、iclass 只读状态与按日历史（2026-10-12 查询到 2 条已签到记录）。
- 钥匙串兼容性：多次 ad-hoc 重新签名后，旧凭据条目的 ACL 可能要求系统授权；读取已改为**非阻塞 + 5 秒超时**，超时后回到登录页并提示“钥匙串需要授权”。首次运行或更新后若出现询问，选择“始终允许”即可继续自动登录。
- 详细验收记录见 [ACCEPTANCE.md](ACCEPTANCE.md)，实现范围见 [IMPLEMENTATION.md](IMPLEMENTATION.md)。

### 已知限制与风险

- **写操作需人工确认**：图书馆预约/取消、iclass 签到提交均可使用，但每次都需要你逐项确认；结果不明确时只提示核实，不会自动重发。
- **希冀（Judge）来源暂时下线**：真实课程列表结构与客户端预期不一致，且本机账号没有该来源作业；代码与测试保留，待拿到真实页面脱敏样本后再启用。作业页当前只显示 SPOC。
- **本科账号链路**（课表、考试、成绩）与验证码分支未做真实账号验收。
- 系统通知投递/点击、登录项批准、全局快捷键尚未人工验收。
- 浅色模式、窄窗口、键盘与 VoiceOver 完整流程未验收；无 UI 自动化测试。
- 研讨室专用预约、阳光打卡、作业提交/附件上传不在本版本范围。
- 图书馆座位历史估算需积累至少 3 个同星期/同小时样本后才显示。

### 运行方式

- 版本标识：`CFBundleShortVersionString` 与 tag 一致（发布构建由 CI 注入）。
- 直接下载：从 [GitHub Releases](https://github.com/JUANWANG-BUAA/ginkgo/releases/latest) 获取 DMG（拖入 Applications）或 ZIP；发布资产附 `checksums.txt`。
- 首次运行或更新后，macOS 可能询问一次钥匙串访问权限：发布包与本地构建都使用同一张稳定自签名证书（`Ginkgo Local Signing`），选择“**始终允许**”后后续构建/更新不再询问；即使弹窗未处理，应用也会在 5 秒后回到登录页并给出提示。签名方案详见 [SIGNING.md](SIGNING.md)。
- 自用：用 Xcode 16+ 打开 `BUAA-Assistant.xcodeproj`，⌘R 运行（本机已验证；Xcode 27.0 / macOS）。
- 命令行构建（`CODE_SIGNING_ALLOWED=NO`）的产物资源未封签，Dock 会显示白色占位图标；本地运行请用 Xcode ⌘R，或构建后执行 `codesign --force --sign - <App>` 再启动。
- 分发他人：当前未配置 Developer ID 签名与公证，首次打开可能需要在「系统设置 → 隐私与安全性」中允许；也可用内置更新在应用内升级。
