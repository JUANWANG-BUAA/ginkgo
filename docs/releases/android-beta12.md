# Ginkgo Android Beta.12

版本：`0.1.0-beta.12+22`（versionCode 22）· GitHub prerelease

Release：[android-v0.1.0-beta.12](https://github.com/JUANWANG-BUAA/ginkgo/releases/tag/android-v0.1.0-beta.12)

- 重构首页工作台与全应用视觉层次：页头展示日期与教学周，课程签到直接融入今日课程时间轴，统一按钮对比度、图标与精简卡片排布。
- 准确区分本人课程与助教课程：SPOC 作业与首页课程签到自动过滤助教课程，避免误展示他课提醒。
- 新增本科生教务、财务收入只读、网费与校园网流量、课程评教状态检查，以及 WebVPN 链路与签到码快捷体验优化。
- 支持离线首屏缓存、Android 桌面今日课表小组件，以及一键导出课表为 `.ics` 日历文件。

升级前建议备份重要个人待办；若曾安装本地调试包，请先卸载后再安装签名版。测试版，真实账号与写入验收仍按 [MIRROR-TODO](../MIRROR-TODO.md) 记录。
