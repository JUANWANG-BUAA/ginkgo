# Ginkgo Android 0.1.0-alpha.9

- 页面切换更连贯：点击底栏会左右翻页，也可以直接左右轻扫相邻栏目。
- 新增 SPOC 学习中心：按课程查看公告、资料目录和测验信息，并可保存资料附件。
- 新增研究生学分地图、本人借阅入口和课程／待办提醒，工作台能直接进入这些栏目。
- 作业详情可查看附件与提交状态；个人文件提交需要明确确认，结果不明时先回查。
- 课表顶部更紧凑，大字号周次不再溢出；签到题目支持验证码图片，并修复若干状态误报。

提醒：课表、作业与个人待办保存在本机或账号隔离缓存中，个人待办完成不代表学校作业已提交。提交、借阅、校车余票等学校业务仍应以官方页面与学校记录为准；升级前请备份重要待办，暂不建议降级或卸载。
