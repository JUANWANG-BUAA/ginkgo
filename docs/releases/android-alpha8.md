# Ginkgo Android 0.1.0-alpha.8

- 图书馆公开查书上线：按书名/著者检索全校书目，查看馆藏与索书号，支持翻页。
- 校车时刻表官方入口：应用内查看计划班次，可一键跳转官方页面。
- 横竖屏旋转不再丢位置：平板跨宽度旋转后停留在当前页面，填写中的表单内容保留。
- 下拉刷新更可靠：读取中再下拉会在完成后自动补刷；学校系统响应过慢时最多等待 45 秒并给出可重试提示。
- 作业与页面细节修复：已提交作业不再显示截止倒计时，加载失败与空数据使用不同图标，研讨室操作不再卡住其他页面。

提醒：待办只保存在本机，完成不代表学校提交；升级前请备份重要待办，暂不建议降级或卸载。研讨室写入仍属实验功能，真实预约、审批和取消请逐项核对学校记录。
