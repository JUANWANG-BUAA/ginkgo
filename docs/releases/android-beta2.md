# Ginkgo Android 0.1.0-beta.2

- 公开信息查询与账号登录态隔离，常用服务可在目录中本地搜索。
- 新增按需校园卡余额查询，金额默认遮挡，离开页面或切换账号后清除。
- 工作台仅在有近期考试时显示考试提醒，课程、作业和待办信息更清楚。
- 优化窄屏与大字号排版，并区分加载、确认无数据和失败状态。
- 刷新、退出和提醒操作更可靠，减少页面卡住与旧数据误显示。

提醒：Beta 版本仍在完善。校园卡余额和校园活动的真实设备验证尚未完成；校园卡余额需登录学校系统，默认隐藏。预约、签到、上传和提交仍须逐次确认；结果不明时先回查，不会自动重发。
