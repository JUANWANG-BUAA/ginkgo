# Ginkgo Android Beta.6

版本：`0.1.0-beta.6+16`（versionCode 16）
产物：`Ginkgo-0.1.0-beta.6-android-arm64.apk`（arm64-v8a，正常 main 入口）

## 本次修复

- **校外模块不再要求先存密码**：登录成功时把本次使用的凭据只留在内存里，网关需要自建 CAS 会话时优先读保险库、没有就用这份内存凭据；退出登录、切换账号或登录失败即清除，从不写盘。此前不勾选“记住密码”，签到、图书馆等被网关拦下的模块会直接报会话失效且重试无效。
- **登录不再被误判为需要验证码**：密码提交被学校接受（`302` + `CASTGC`）后，登录链不再跟随目标服务的跳转重新进入 CAS；该跳转在不通的网络里会掉进网关并回到未认证的 CAS，被要求验证码。
- **作业截止时间不再提前 8 小时**：规则端口收到的北京时间被当作绝对时刻，离截止 40 分钟的作业会显示“已截止”；换算收口到一处，签到窗口判断同时修正。
- **工作台直接显示签到状态**：首页自己读取当天签到，读到就显示“N 门课可签到”或“今天无需签到”，读不到只留一行安静提示，不再用“首页不读取学校数据”的占位文案。

## 验证

- `bash scripts/check-mirror.sh` 全绿：Rust 386 用例、Flutter 685 用例、FRB 绑定零漂移。
- 真实账号在 API 37 模拟器上登录并逐页复验：课表、作业、校园通知均为真实数据；作业截止边界与签到窗口有共享规则表回归。
- 本机网络下 `iclass.buaa.edu.cn` 的 443 与 8346 均 TCP 超时，WebVPN 网关登录页本身要求验证码（干净客户端亦然），因此签到无法在本环境完成真实读取，未据此宣称已验收。

- 真实设备、TalkBack、Windows 与写操作仍按既有验收边界分别记录。
