# Ginkgo Android 0.1.0-alpha.7

- 工作台更清爽，下一节课、近期作业和待办更好找，完整课表按需展开。
- 作业可加入个人待办、查看来源，已完成事项收起，管理更顺手。
- 常用入口可按账号定制，新增七组强调色和轻量栏目切换动效。
- 研讨室支持填写预约、手动拼图和取消；结果不明时先核对订单，重启也不会自动重发。
- 启动时轻提示新版，深色和大字号下的阅读与按钮更清楚。

提醒：待办只保存在本机，完成不代表学校提交；升级前请备份重要待办，暂不建议降级或卸载。研讨室写入仍属实验功能，真实预约、审批和取消请逐项核对学校记录。
