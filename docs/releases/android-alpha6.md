# Ginkgo Android 0.1.0-alpha.6

版本 `0.1.0-alpha.6+7`，Android 7.0+ / ARM64，签名与既往 Alpha 包一致。

- 签到在课前 10 分钟开放，课程结束关闭，每节课仅提醒一次；仍需手动确认。
- 未完成个人课程作业在截止前 48 / 24 小时提醒，标签页增加未读数字角标。
- 新增错误 hint、行动建议及可复制的脱敏诊断。
- 教学楼 CGYY 新增 iOS 原生页面对照表单、时段网格、人数步进、手动拼图、单次预约 / 取消与回查保护。
- 新 UI 使用统一的分组、语义色、原生风格控件和确认弹窗，覆盖深浅色及大字号布局检查。

API 37 ARM64 模拟器已实测分组表单、时间门禁、系统闹钟投递、去重和取消；全部使用合成数据。通知使用非精确定时，省电 / 强停 / 重启可能影响投递；重启后请打开应用重排。提醒只基于最近成功读取的数据，不保证后台学校状态实时更新，不会自动签到或提交作业。

CGYY 为实验写入功能：真实预约、审批、取消尚未人工往返验收。结果不明时请先回查，勿重复提交。未执行真实学校账号操作。跨平台未完成实机逐像素或完整读屏验收。

下载 APK 后可用同页 `checksums.txt` 校验 SHA-256。完整证据与限制见 `docs/archive/mirror/MIRROR-ALPHA6.md`。
