Core Features

三件每天都会用的事

课表、签到、预约是校园生活的日常动线；Ginkgo 把它们做成原生、快速、可信的一组页面。

Schedule

课表

星期 × 节次网格，本科与研究生两套教务都能读；联网刷新，断网看缓存。

  • 周网格、每日清单、学期总览三种视图
  • 同课连续节次自动合并，课程稳定配色
  • 本科考试安排：时间、考场、座位号
  • 菜单栏显示「下一节课」，缓存离线可看
Check-in

签到 / 打卡

iclass 课程签到状态常驻核对，提交必须由你逐门确认。

  • 只读状态查询 + 按日历史查询
  • 提交前后都回查，只有确认已签到才算成功
  • 结果不明确时只提示核实，绝不自动重发
  • 状态变化时应用内提醒，可选系统通知
Booking

图书馆预约

楼馆 → 分区 → 当前时段 → 座位，四步走完；预约与取消都有确认。

  • 自动定位今天正在开放的预约时段
  • 官网公开的校区实时在馆人数与本机小时趋势
  • 预约记录分页读取，已结束/取消的记录只读展示
  • 写请求不自动重发，未知结果先回查状态

成绩与参考绩点

学期切换、加权均分与参考绩点，计算口径写清说明。

空教室

校区与日期查询，楼栋概览 / 房间列表 / 节次对照。

学校作业

SPOC 只读列表与详情：教师、截止时间、分值、提交状态。

本机待办

截止时间、完成与删除，按账号隔离保存在本机。

校园通知

北航通知公告摘要，今天页一屏看完。

菜单栏面板

下一节课、临期作业与打开主窗口，5 秒看完。

课前提醒

本地通知，默认关闭；正文不含课程名与地点。

全局快捷键

⌃⌥B 唤起主窗口，可在应用菜单关闭。

多账号隔离

缓存按账号摘要分文件，切换账号不串数据。

登录时自启

由 macOS 登录项管理，状态以系统为准。

深浅色与减少动态

跟随系统外观，动效尊重「减少动态效果」。

一键清缓存

查询快照可清；个人待办不会被误删。

Privacy by design

数据只留在这台 Mac

Ginkgo 只直连学校系统，没有自建服务端、没有第三方统计。 密码、Cookie 与查询缓存都在本机；仓库里也永远不会出现真实账号数据。

阅读完整隐私说明 →

  • 密码仅在勾选「记住密码」后写入 macOS 钥匙串，登出即删除。
  • 会话 Cookie交给系统管理，WebVPN 会话不落盘。
  • 查询缓存按账号摘要分文件存放，可在设置中一键清除。
  • 日志只记录阶段、状态码与错误码，不含正文、账号与课程内容。
  • 截图与文档姓名、学号、课程信息入库前一律打码。

Get Started

开始使用

需要 macOS 14+ 与 Xcode 16+。当前是 0.1.0-alpha，只读链路是验收重点。

# 克隆仓库
git clone https://github.com/JUANWANG-BUAA/ginkgo.git
cd ginkgo

# 用 Xcode 打开并 ⌘R 运行（推荐，自动本地签名）
open BUAA-Assistant.xcodeproj

# 或者命令行跑全量测试
xcodebuild test -project BUAA-Assistant.xcodeproj \
  -scheme BUAA-Assistant -destination 'platform=macOS' \
  CODE_SIGNING_ALLOWED=NO
  • 登录即用：CAS 登录、可选记住密码、启动会话验证。
  • 首次运行建议从「今天 → 课表 → 图书馆」走一遍。
  • 命令行构建产物未封签时，Dock 图标可能需要 codesign --force --sign -。
Alpha 说明：图书馆预约/取消与 iclass 签到写入尚未完成真实往返验收； 希冀（Judge）作业来源暂时下线，当前只显示 SPOC； 本科账号链路与验证码分支仍待真机验收。使用写操作前请先读 发布说明。
