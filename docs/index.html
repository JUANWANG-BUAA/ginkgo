本地直连与数据边界

请求在手机本机发出，
没有自建中转服务器。

所有学校请求均在应用进程内由本地 Rust 模块直连北航系统，或经北航官方 WebVPN 访问，账号密码与 Cookie 不经过第三方服务器。

凭据与匿名会话分离
仅在主动勾选“记住密码”后写入系统 Android Keystore；校车、宣讲与新闻等公开信息使用无 Cookie 匿名会话读取。
账户数据仅存内存
校园卡、网费、财务收入与本人借阅默认遮挡金额，并在 Rust 层剔除银行卡号与证件号，离开页面或退到后台立即清空内存，不写入磁盘。
写操作不自动重发
预约、取消与作业提交均需本人确认后单次发送；若网络超时或返回状态不明，只允许只读回查，不自动重发。

带到你的 Android 手机上

三步，开始安排今天。

支持 Android 7.0 及以上的 64 位 ARM 设备，安装包内置应用更新校验能力。

  1. 01

    下载官方签名 APK

    从本页或 GitHub Release 获取安装包；使用第三方镜像加速下载后请核对官方 SHA-256 摘要。

  2. 02

    系统确认安装

    按 Android 系统引导允许本次安装。升级新版可直接覆盖安装以保留本机个人待办。

  3. 03

    校内直连、WebVPN 或离线预览

    登录本人北航统一身份认证即可使用；校园网内外可按需切换直连或官方 WebVPN，也可先体验离线演示。

不接资金与代填提交接口

校园卡、网费与财务模块仅做只读查询，不接入充值、挂失、转账或应用内评教提交写操作。

常见疑问

开始之前，你可能想了解。

这是学校官方应用吗？＋

不是。Ginkgo 是非官方个人开源项目，与北京航空航天大学及其任何部门无隶属、合作或授权关系。重要信息请以学校官方系统为准。

在校外网络可以使用吗？＋

可以。支持自动、直连与北航官方 WebVPN 路线切换；校外环境可通过本人北航统一身份认证经官方 WebVPN 访问支持的校内服务。

财务、校园卡和网费查询安全吗？＋

这些模块均为用户手动触发的纯只读请求，金额默认遮挡且剥离证件号与银行卡号，数据仅存于当前页面内存，切后台或离页即刻销毁，不写入本地磁盘。

为什么课程评教只显示状态而不支持应用内一键评教？＋

为尊重教学评价严肃性并规避上游网页端状态锁死风险，应用仅提供应评课程与未评数量提醒，并提供官方评教系统入口在浏览器中由本人完成。
