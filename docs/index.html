这一版可以做什么

  • 周课表、每日清单、学期与有数据时的考试安排。
  • 签到当天与历史状态；图书馆座位、当前预约、历史记录及公开人数。
  • SPOC 作业列表与详情、成绩、空教室、博雅目录、研究生报告与本地待办。
  • 设置中的本机自检、缓存清理、网络路线与更新检查。

测试版边界：签到提交、预约、取消、离馆、选退课和作答上传均未开放。提醒、验证码图片、博雅已选统计、图书馆趋势等仍在迁移。已完成有限的设备与只读验证，不代表所有账号与场景均通过。

Core Features

macOS · 从日常到培养过程

以下为 macOS 功能；Android 已实现的范围与暂未开放的功能见下方，不同平台进度不同。

Schedule

课表

星期 × 节次网格，本科与研究生两套教务都能读；联网刷新，断网看缓存。

  • 周网格、每日清单、学期总览三种视图
  • 同课连续节次自动合并，课程稳定配色
  • 本科考试安排：时间、考场、座位号
  • 菜单栏显示「下一节课」，缓存离线可看
Check-in

签到 / 打卡

iclass 课程签到状态常驻核对，提交必须由你逐门确认。

  • 只读状态查询 + 按日历史查询
  • 提交前后都回查，只有确认已签到才算成功
  • 结果不明确时只提示核实，绝不自动重发
  • 状态变化时应用内提醒，可选系统通知
Booking

图书馆预约

楼馆 → 分区 → 当前时段 → 座位，四步走完；预约与取消都有确认。

  • 自动定位今天正在开放的预约时段
  • 官网公开的校区实时在馆人数与本机小时趋势
  • 预约记录分页读取，已结束/取消的记录只读展示
  • 写请求不自动重发，未知结果先回查状态
Graduate

研究生教务

按执行报告展示“总要求 → 类别 → 课组 → 修读记录”，每层缺口独立计算。

  • 已认定、在修、待考核分开展示，不把在修当作已获
  • 培养方案章节、课程池、成绩与考试数量
  • 部分刷新失败保留旧数据并标注来源时间
  • 课程名称、教师与分类可搜索筛选
Liberal Arts

博雅课程

课程库、已选课程与完成统计，按类别和关键词快速定位。

  • 课程详情含教师、地点、人数与校区
  • 已选课程与完成学分统计
  • 只读浏览，不提供选课/退选写操作
  • 按账号隔离的本地缓存，进入页面先看旧结果
Venue

教学楼研讨室

教学楼 CGYY 的场地、时段、订单与门锁密码，预约前二次确认。

  • 校区 / 楼栋 / 日期 / 时段与参与人
  • 提交前复核空档，结果不明时不自动重发
  • 我的预约、取消与门锁密码独立展示
  • 真实写操作仍需逐次人工验收

成绩与参考绩点

学期切换、加权均分与参考绩点，计算口径写清说明。

空教室

校区与日期查询，楼栋概览 / 房间列表 / 节次对照。

学校作业

SPOC 只读列表与详情：教师、截止时间、分值、提交状态。

本机待办

截止时间、完成与删除，按账号隔离保存在本机。

校园通知

北航通知公告摘要，今天页一屏看完。

菜单栏面板

下一节课、临期作业与打开主窗口，5 秒看完。

iOS 工作台

iPhone 底部 TabView / iPad 侧栏，复用同一套客户端与缓存。

课前提醒

本地通知，默认关闭；正文不含课程名与地点。

全局快捷键

⌃⌥B 唤起主窗口，可在应用菜单关闭。

多账号隔离

缓存按账号摘要分文件，切换账号不串数据。

登录时自启

由 macOS 登录项管理，状态以系统为准。

内置更新

从 GitHub Releases 检查新版本，一键下载安装，不清缓存。

深浅色与减少动态

跟随系统外观，动效尊重「减少动态效果」。

一键清缓存

查询快照可清；个人待办不会被误删。

Privacy by design

账号数据保存在本机

校园数据直接请求学校系统；版本检查访问 GitHub。没有自建账号服务端、没有第三方统计。 密码、Cookie 与查询缓存都在本机；仓库里也永远不会出现真实账号数据。

阅读完整隐私说明 →

  • 密码仅在勾选「记住密码」后写入 Apple 钥匙串或 Android Keystore 保护的安全存储，登出即删除。
  • 会话 Cookie由各平台的本机会话管理；Android 查询会话不落盘。
  • 查询缓存按账号隔离。macOS 提供本地快照；Android 当前为进程内快照，关闭进程后需联网重读。
  • 日志只记录阶段、状态码与错误码，不含正文、账号与课程内容。
  • 截图与文档姓名、学号、课程信息入库前一律打码。

Get Started

开始使用

macOS 14+ 与 Android 7.0+（arm64）分别下载。iOS 17+ 目前从源码构建，Windows 镜像仍待实机验收。

Download

macOS 客户端

macOS 14+ · 通用（Apple 芯片 / Intel）· Ginkgo-*.dmg

下载 DMG ZIP 校验和 
# 克隆仓库
git clone https://github.com/JUANWANG-BUAA/ginkgo.git
cd ginkgo

# 用 Xcode 打开并 ⌘R 运行（推荐，自动本地签名）
open BUAA-Assistant.xcodeproj

# 或者命令行跑全量测试
xcodebuild test -project BUAA-Assistant.xcodeproj \
  -scheme BUAA-Assistant -destination 'platform=macOS' \
  CODE_SIGNING_ALLOWED=NO
  • 登录即用：CAS 登录、可选记住密码、启动会话验证。
  • 首次运行建议从「今天 → 课表 → 图书馆」走一遍。
  • 命令行构建产物未封签时，Dock 图标可能需要 codesign --force --sign -。
macOS Alpha 说明：打卡、图书馆座位与教学楼研讨室预约已可用（写操作都需要你逐项确认，结果不明确时不会自动重发）； 希冀（Judge）作业来源暂时下线，当前只显示 SPOC； 正式签名包的真实账号全链路、本科账号与验证码分支仍待真机验收。详见 发布说明。
