# Android Beta.1 发布收口与宣传页重制设计

## 目标

为 `0.1.0-beta.1+11` 形成可审计的发布候选，并把项目主页改成以 Android Beta 下载、安装和反馈为核心的宣传页。自动化通过、真实业务验收和公开发布分别记录，不互相替代。

## 范围

本轮做两件事：

1. 审核并修复可复现的 Beta 发布阻断问题，验证正常入口签名包和 Alpha.9 到 Beta.1 的覆盖升级。
2. 重制 `docs/index.html`、`docs/landing.css`、`docs/landing.js` 及相关分享素材和对外文案，主推 Android。

不新增校园功能，不大规模重构，不修改冻结的 Apple 功能，不执行真实学校写操作，不自动使用真实账号，不自动创建标签或公开 Release。Windows 仅保持共享代码可编译。

## 发布候选审核

### 审核面

- 认证、账号隔离、迟到响应与失败保留旧数据。
- 学校写操作的逐次确认、单次提交、结果不明禁止重发与回查。
- Android Keystore、查询快照、个人待办、日志与宣传素材的隐私边界。
- 正常 `main.dart` 入口、版本与包名、ARM64、非 debuggable、测试驱动排除、zipalign、签名证书和 SHA-256。
- 更新下载、摘要与签名校验、静态下载回退和发布说明的一致性。

只修复有代码或测试证据的问题，并增加能抓住原问题的回归测试。真实认证、物理设备和学校写入的缺口继续保留，不靠放宽断言消除。

### 验证

- 运行 `bash scripts/check-mirror.sh` 和 `git diff --check`。
- 构建正常入口 ARM64 Release；签名只使用维护者已有的外部配置，缺失时明确受阻，不回退 Debug。
- 核验 APK 版本、包名、ABI、签名证书、摘要及无 integration test 驱动。
- 从官方 Alpha.9 签名包覆盖升级，使用合成个人待办验证版本推进、首次安装时间和本机待办保留。
- 能运行的 Android 合成设备测试按改动范围执行；结果不表述为物理设备或真实学校验收。

### 发布门槛

本地候选完成要求上述自动化、签名包和模拟器覆盖升级通过。公开前仍需维护者完成物理 Android 的 TalkBack、大字号、系统返回与常用流程抽检；未完成时明确列为外部阻断项。

## 宣传页重制

### 信息结构

沿用现有银杏绿、serif 标题和 Android 离线演示界面素材，不另起品牌风格。页面按以下顺序组织：

1. 首屏：Android Beta 身份、核心收益、主下载按钮和手机界面。
2. 高频场景：今天、课表与作业、签到、图书馆与研讨室。
3. 界面与离线演示：减少重复截图，保留可放大查看。
4. 安装与兼容性：Android 7.0+、ARM64、三步安装、升级与数据提醒。
5. Beta 边界：非官方项目、已知限制、写操作确认和学校官方记录优先。
6. 隐私与反馈：本机数据、学校请求、第三方下载代理的区别，以及脱敏反馈入口。
7. 次要平台：Windows 与冻结的 Apple 平台收缩到页尾。

### 文案口径

- Beta 不是稳定版，不使用“全面稳定”“所有功能已验收”等表述。
- 不说绝对化的“数据不上传”；说明查询会直连学校或经北航 WebVPN，不经过项目自建中转服务器。
- “断网看缓存”必须与实际快照能力一致，不暗示重启后完整离线可用。
- 未验收的借阅、门锁码、学校写入和实时余票不得包装成稳定能力。
- 发布前页面继续指向 Alpha.9；Beta Release 存在后，脚本才自动切换版本、下载、校验和与发布说明。

### 视觉、性能与无障碍

- 首屏强化一个主行动，减少平台状态和长段说明的竞争。
- 制作 1200×630 社交分享图；保留原始 PNG，生成适合页面展示尺寸的 WebP 与回退资源。
- 图片按显示尺寸加载，非首屏延迟加载，视频不自动播放。
- 检查 320px 窄屏、移动导航、键盘焦点、灯箱焦点恢复、减少动态效果和文字对比度。
- GitHub API 失败或限流时保留可用的静态版本与官方下载链接；不依赖第三方代理作为主入口。

## 文档与反馈

同步更新 README、`docs/PROMOTION.md`、`docs/RELEASE-NOTES.md`、Beta.1 发布记录及 `docs/MIRROR-TODO.md` 中实际完成的条目。发布说明保持 3–5 条用户收益，已知限制单独说明。

补充面向 Beta 试用的问题反馈入口和脱敏提示；不新增重复待办清单，不记录真实账号或个人数据。

## 完成定义

本轮完成表示：代码与页面改动均已验证，发布候选证据和剩余人工门槛写清，宣传页在手机与桌面浏览器实际检查通过。只有维护者完成物理设备抽检并主动发布后，才将 Beta.1 标记为公开版本。
