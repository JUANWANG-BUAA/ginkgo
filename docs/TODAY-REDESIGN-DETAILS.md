# Today 页面 UI 实质性改进说明

## 🎯 改进的核心 - TodayActionRow 组件

这是"今天"页面最核心的卡片组件，用于显示下一节课、待办任务等关键信息。

### 改进 1: 视觉层次 - 排版精细化

**之前:**
```
fontSize 依赖 emphasized flag，大小跳跃：13/15/17/20 px
fontWeight 混乱: w400/w500/w600，无规律
```

**之后:**
```
标题 (emphasized): 18px w700 with -0.3 letter-spacing
标题 (normal): 16px w600 with -0.2 letter-spacing
副标题: 13px w400 with -0.1 letter-spacing
状态标签: 11px w600 uppercase spacing

Swift 特征: 严格的排版层级，精准的 letter-spacing 控制
```

### 改进 2: 状态标签 - 从文本到徽章

**之前:**
```
纯文本，颜色变化，没有背景
```

**之后:**
```
┌─────────────────┐
│ ⚫ 下一节课      │ ← 有背景、有圆角
└─────────────────┘
- 半透明彩色背景 (12% opacity)
- 圆角 6pt
- 精确的 padding (8, 3)
- 大写字母间距 (letter-spacing: 0.2)

Swift 特征: 徽章设计，清晰的视觉分组
```

### 改进 3: 卡片深度 - 阴影和渐变

**之前:**
```
纯色背景 + 薄边框，完全扁平
```

**之后:**
```
1. 渐变背景
   - 从 5% 透明到 1% 透明
   - 从左上到右下（暗示光源）

2. 精细阴影
   - blur: 6pt, offset: (0, 1)
   - 颜色透明度 8-12% (根据深浅色模式)

3. 边框优化
   - 宽度从 1.0 改为 0.8pt
   - 透明度 12-15% (而不是 18-26%)

Swift 特征: 微妙的阴影和光学效果
```

### 改进 4: 交互反馈 - 按下动画

**之前:**
```
无动画反馈，按了以后没感觉
```

**之后:**
```
两层反馈:
1. 缩放动画: 97% scale (从 1.0 到 0.97)
   - 时长 120ms (snappy)
   - Curve: easeInOut

2. 透明度变化: 100% → 70%
   - 同时发生，强化按下感觉

结果: 按下时卡片明显变小并变暗，松开时流畅恢复

Swift 特征: 多层级反馈，物理感
```

### 改进 5: 间距系统 - 严格的栅栏

**之前:**
```
Emphasized: (16, 14) padding
Normal: GinkgoSpacing.edgeInsetsListTile (16, 10)

混乱的 margin: 不统一
```

**之后:**
```
使用设计系统常量:
- Emphasized margin: (12, 8)
- Normal margin: (4, 6)
- 内部 padding: (16, 14) 或 (16, 12)

所有间距都是 4pt 的倍数（8pt 栅栏）

Swift 特征: 严格的间距系统
```

### 改进 6: 色彩应用 - 语义化颜色

**之前:**
```
statusColor 参数随意，background alpha 值硬编码
```

**之后:**
```
明确的色彩意图:
- 强调(emphasized): 使用 GinkgoColors.accent
- 状态标签: 使用 statusColor 或 accent
- 边框: cardTint.withOpacity(isDark ? 0.15 : 0.12)
- 阴影: cardTint.withOpacity(isDark ? 0.08 : 0.04)

色彩在深浅色模式下自动调整

Swift 特征: 语义化色彩系统
```

## 🏗️ 代码质量

新版本中的改进：

| 方面 | 改动 |
|------|------|
| **类型** | StatelessWidget → StatefulWidget (为了处理动画) |
| **包体积** | +200 行代码，但都是有意义的 UI 逻辑 |
| **性能** | 单个 AnimationController，无额外开销 |
| **无障碍** | 保留所有语义化标签，动画尊重 reduce-motion |
| **可维护性** | 使用 GinkgoSpacing/GinkgoColors/GinkgoMotion，集中管理 |

## 🎬 在模拟器中看到的具体变化

1. **打开"今天"页面** → 注意"下一节课"卡片
   - 卡片有明显的阴影深度感
   - 状态标签是一个清晰的徽章，不是纯文本
   - 标题看起来更有力量感

2. **按下卡片** → 感受交互反馈
   - 卡片立刻缩小到 97%
   - 同时变暗到 70% 透明度
   - 松开时流畅恢复（120ms）

3. **在浅色/深色模式切换** → 观察色彩适应
   - 阴影深度根据背景自动调整
   - 边框透明度根据亮度自动调整
   - 渐变方向保持光学效果

4. **横屏旋转** → 检查布局自适应
   - 卡片宽度自适应
   - 间距系统保持一致
   - 没有破损或重叠

## 💡 Swift 设计特征体现

这个改进体现的 Swift/iOS 设计原则：

| 原则 | 体现方式 |
|------|--------|
| **Clarity** | 徽章设计清晰表达状态 |
| **Deference** | 内容优先，装饰品最小化 |
| **Depth** | 阴影和渐变创造层次感 |
| **Responsiveness** | 按下反馈即时而流畅 |
| **Consistency** | 所有间距、颜色使用设计系统 |
| **Beauty** | letter-spacing、gradient、shadow 的微妙配合 |
